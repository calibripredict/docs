Calibri provides four cancel endpoints so you can close out resting orders at any granularity — from a single order by ID to every open order across all markets simultaneously. All cancel requests are processed synchronously; a `success: true` response confirms the orders have been removed from the book.

<Note>
  All cancel endpoints require L2 authentication. Include the `POLY_ADDRESS`, `POLY_API_KEY`, `POLY_PASSPHRASE`, `POLY_SIGNATURE`, and `POLY_TIMESTAMP` headers with every request.
</Note>

---

## Cancel a Single Order — DELETE /order/{id}

Cancel one open order by its order ID.

```
DELETE https://clob.calibri.com/order/{id}
```

### Path Parameters

<ParamField path="id" type="string" required>
  The order ID to cancel. This is the `orderId` value returned when the order was placed.
</ParamField>

### Response

<ResponseField name="success" type="boolean">
  `true` if the order was successfully cancelled.
</ResponseField>

### Example Response

```json
{ "success": true }
```

<CodeGroup>

```bash cURL
curl -X DELETE "https://clob.calibri.com/order/0x1234abcd..." \
  -H "POLY_ADDRESS: 0xabc123..." \
  -H "POLY_API_KEY: your-api-key" \
  -H "POLY_PASSPHRASE: your-passphrase" \
  -H "POLY_SIGNATURE: hmac-signature" \
  -H "POLY_TIMESTAMP: 1700000000"
```

```typescript TypeScript
const orderId = "0x1234abcd...";
const timestamp = Math.floor(Date.now() / 1000).toString();

const res = await fetch(`https://clob.calibri.com/order/${orderId}`, {
  method: "DELETE",
  headers: {
    POLY_ADDRESS: "0xabc123...",
    POLY_API_KEY: "your-api-key",
    POLY_PASSPHRASE: "your-passphrase",
    POLY_SIGNATURE: computeHmacSignature(timestamp),
    POLY_TIMESTAMP: timestamp,
  },
});

const { success } = await res.json();
console.log("Cancelled:", success);
```

</CodeGroup>

## Cancel Multiple Orders — DELETE /orders

Cancel up to **1,000 orders** in a single request by providing an array of order IDs.

```
DELETE https://clob.calibri.com/orders
```

### Request Body

<ParamField body="ids" type="array" required>
  An array of order ID strings to cancel. Maximum 1,000 IDs per request.
</ParamField>

### Response

<ResponseField name="success" type="boolean">
  `true` if the cancellation request was processed.
</ResponseField>

<ResponseField name="not_canceled" type="array">
  An array of order IDs that could not be cancelled (e.g., already filled or not found). An empty array means all orders were cancelled successfully.
</ResponseField>

### Example Response

```json
{
  "success": true,
  "not_canceled": []
}
```

<CodeGroup>

```bash cURL
curl -X DELETE "https://clob.calibri.com/orders" \
  -H "Content-Type: application/json" \
  -H "POLY_ADDRESS: 0xabc123..." \
  -H "POLY_API_KEY: your-api-key" \
  -H "POLY_PASSPHRASE: your-passphrase" \
  -H "POLY_SIGNATURE: hmac-signature" \
  -H "POLY_TIMESTAMP: 1700000000" \
  -d '{
    "ids": ["0x1234abcd...", "0x5678efgh...", "0x9012ijkl..."]
  }'
```

```typescript TypeScript
const timestamp = Math.floor(Date.now() / 1000).toString();

const res = await fetch("https://clob.calibri.com/orders", {
  method: "DELETE",
  headers: {
    "Content-Type": "application/json",
    POLY_ADDRESS: "0xabc123...",
    POLY_API_KEY: "your-api-key",
    POLY_PASSPHRASE: "your-passphrase",
    POLY_SIGNATURE: computeHmacSignature(timestamp),
    POLY_TIMESTAMP: timestamp,
  },
  body: JSON.stringify({
    ids: ["0x1234abcd...", "0x5678efgh...", "0x9012ijkl..."],
  }),
});

const { success, not_canceled } = await res.json();
if (not_canceled.length > 0) {
  console.warn("Some orders were not cancelled:", not_canceled);
}
```

</CodeGroup>

## Cancel All Orders for a Market — DELETE /orders/market

Cancel every open order you have in a specific prediction market, identified by its condition ID. This is useful when you want to pull your quotes from a single market without affecting positions in other markets.

```
DELETE https://clob.calibri.com/orders/market
```

### Request Body

<ParamField body="market" type="string" required>
  The condition ID of the market whose orders you want to cancel.
</ParamField>

### Response

<ResponseField name="success" type="boolean">
  `true` if all orders for the specified market were cancelled.
</ResponseField>

### Example Response

```json
{ "success": true }
```

<CodeGroup>

```bash cURL
curl -X DELETE "https://clob.calibri.com/orders/market" \
  -H "Content-Type: application/json" \
  -H "POLY_ADDRESS: 0xabc123..." \
  -H "POLY_API_KEY: your-api-key" \
  -H "POLY_PASSPHRASE: your-passphrase" \
  -H "POLY_SIGNATURE: hmac-signature" \
  -H "POLY_TIMESTAMP: 1700000000" \
  -d '{
    "market": "0xabc123def456789..."
  }'
```

```typescript TypeScript
const timestamp = Math.floor(Date.now() / 1000).toString();

const res = await fetch("https://clob.calibri.com/orders/market", {
  method: "DELETE",
  headers: {
    "Content-Type": "application/json",
    POLY_ADDRESS: "0xabc123...",
    POLY_API_KEY: "your-api-key",
    POLY_PASSPHRASE: "your-passphrase",
    POLY_SIGNATURE: computeHmacSignature(timestamp),

  body: JSON.stringify({
```

## Cancel All Open Orders — DELETE /orders/all

Cancel every open order across all markets for your account in a single call. This is the fastest way to zero out your entire book.

```
DELETE https://clob.calibri.com/orders/all
```

### Request Body

No request body is required.

### Response

<ResponseField name="success" type="boolean">
  `true` if all open orders were cancelled.
</ResponseField>

### Example Response

```json
{ "success": true }
```

<CodeGroup>

```bash cURL
curl -X DELETE "https://clob.calibri.com/orders/all" \
  -H "POLY_ADDRESS: 0xabc123..." \
  -H "POLY_API_KEY: your-api-key" \
  -H "POLY_PASSPHRASE: your-passphrase" \
  -H "POLY_SIGNATURE: hmac-signature" \
  -H "POLY_TIMESTAMP: 1700000000"
```

```typescript TypeScript
const timestamp = Math.floor(Date.now() / 1000).toString();

const res = await fetch("https://clob.calibri.com/orders/all", {
  method: "DELETE",
  headers: {
    POLY_ADDRESS: "0xabc123...",
    POLY_API_KEY: "your-api-key",
    POLY_PASSPHRASE: "your-passphrase",
    POLY_SIGNATURE: computeHmacSignature(timestamp),
    POLY_TIMESTAMP: timestamp,
  },
});

const { success } = await res.json();
console.log("All orders cancelled:", success);
```

</CodeGroup>

<Tip>
  If you run automated market-making strategies, consider adding logic to cancel all open orders gracefully on shutdown. Use `DELETE /orders/all` as part of a shutdown hook to ensure stale quotes are never left on the book after a connectivity failure or process crash.
</Tip>
