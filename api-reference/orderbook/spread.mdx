The bid-ask spread is the difference between the lowest ask price and the highest bid price on the order book. A tight spread signals a liquid, competitive market where you can enter and exit positions efficiently. A wide spread indicates thin liquidity and means the implied transaction cost of crossing the book is higher. Use these endpoints to evaluate market quality before placing orders, or to screen for well-priced trading opportunities across multiple markets at once.

<Note>
  All endpoints on this page are public. No authentication is required.
</Note>

---

## Spread — GET /spread

Fetch the current bid-ask spread for a single outcome token.

```
GET https://clob.calibri.com/spread
```

### Query Parameters

<ParamField query="token_id" type="string" required>
  The unique identifier of the outcome token.
</ParamField>

### Response

<ResponseField name="spread" type="string">
  The bid-ask spread as a decimal string — the difference between the best ask and best bid prices (e.g., `"0.02"`).
</ResponseField>

### Example

```json
{ "spread": "0.02" }
```

<CodeGroup>

```bash cURL
curl "https://clob.calibri.com/spread?token_id=71321045679252212594626385532706912750332728571942532289631379312455583992563"
```

```typescript TypeScript
const params = new URLSearchParams({
  token_id: "71321045679252212594626385532706912750332728571942532289631379312455583992563",
});

const res = await fetch(`https://clob.calibri.com/spread?${params}`);
const { spread } = await res.json();
console.log("Bid-ask spread:", spread);
```

</CodeGroup>

<Tip>
  Use the spread as a liquidity quality signal. If the spread is at or near the tick size, the market is highly competitive. Spreads wider than 3–5 ticks typically indicate low liquidity, and crossing the book in those markets will incur meaningful slippage.
</Tip>

## Bulk Spreads — GET /spreads

Fetch bid-ask spreads for multiple tokens in a single request.

```
GET https://clob.calibri.com/spreads
```

**Request body:**

```json
[
  { "token_id": "71321045679252212594626385532706912750332728571942532289631379312455583992563" },
  { "token_id": "52108247361948573920614827193045826371948273645019283756102938471029384756201" }
]
```

**Response:**

```json
[
  {
    "token_id": "71321045679252212594626385532706912750332728571942532289631379312455583992563",
    "spread": "0.02"

    "token_id": "52108247361948573920614827193045826371948273645019283756102938471029384756201",
    "spread": "0.04"
```

## Tick Size — GET /tick-size

Fetch the minimum price increment for an outcome token. Every order price you submit must be an exact multiple of the tick size — prices that fall between ticks are rejected.

```
GET https://clob.calibri.com/tick-size
```

### Query Parameters

<ParamField query="token_id" type="string" required>
  The unique identifier of the outcome token.
</ParamField>

### Response

<ResponseField name="minimum_tick_size" type="string">
  The minimum price increment as a decimal string (e.g., `"0.01"`).
</ResponseField>

### Example

```json
{ "minimum_tick_size": "0.01" }
```

<CodeGroup>

```bash cURL
curl "https://clob.calibri.com/tick-size?token_id=71321045679252212594626385532706912750332728571942532289631379312455583992563"
```

```typescript TypeScript
const params = new URLSearchParams({
  token_id: "71321045679252212594626385532706912750332728571942532289631379312455583992563",
});

const res = await fetch(`https://clob.calibri.com/tick-size?${params}`);
const { minimum_tick_size } = await res.json();
console.log("Tick size:", minimum_tick_size);
```

</CodeGroup>

## CLOB Market Parameters — GET /clob-markets/{condition_id}

Fetch the full set of CLOB parameters for a prediction market, including both of its outcome tokens, market maker incentive thresholds, and resolution status. Use this endpoint to discover token IDs for a given market and to check whether a market is still active.

```
GET https://clob.calibri.com/clob-markets/{condition_id}
```

### Path Parameters

<ParamField path="condition_id" type="string" required>
  The condition ID of the prediction market you want to inspect.
</ParamField>

### Response

<ResponseField name="condition_id" type="string">
  The condition ID of the market — the same value you passed in the path.
</ResponseField>

<ResponseField name="tokens" type="array">
  The outcome tokens for this market. Most binary markets have exactly two tokens: one for "Yes" and one for "No".

  <Expandable title="Token object fields">
    <ResponseField name="token_id" type="string">
      The unique identifier for this outcome token. Use this value as `token_id` in order book, price, and trading endpoints.
    </ResponseField>

    <ResponseField name="outcome" type="string">
      The outcome this token represents (e.g., `"Yes"` or `"No"`).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="rewards" type="object">
  Liquidity reward thresholds for market makers.

  <Expandable title="Rewards object fields">
    <ResponseField name="min_size" type="string">
      The minimum order size (in shares) required to qualify for market maker rewards.
    </ResponseField>

    <ResponseField name="max_spread" type="string">
      The maximum spread allowed while still qualifying for market maker rewards.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="active_resolving" type="boolean">
  Whether the market is currently in the resolution process.
</ResponseField>

<ResponseField name="closed" type="boolean">
  Whether the market has been closed to new orders.
</ResponseField>

### Example Response

```json
{
  "condition_id": "0xabc123def456789...",
  "tokens": [
    {
      "token_id": "71321045679252212594626385532706912750332728571942532289631379312455583992563",
      "outcome": "Yes"
    },
    {
      "token_id": "52108247361948573920614827193045826371948273645019283756102938471029384756201",
      "outcome": "No"
    }
  ],
  "rewards": {
    "min_size": "20",
    "max_spread": "0.10"
  },
  "active_resolving": false,
  "closed": false
}
```

<CodeGroup>

```bash cURL
curl "https://clob.calibri.com/clob-markets/0xabc123def456789..."
```

```typescript TypeScript
const conditionId = "0xabc123def456789...";

const res = await fetch(`https://clob.calibri.com/clob-markets/${conditionId}`);
const market = await res.json();

// Extract token IDs for further queries
const [yesToken, noToken] = market.tokens;
console.log("Yes token ID:", yesToken.token_id);
console.log("No token ID:", noToken.token_id);
console.log("Market closed:", market.closed);
```

</CodeGroup>
