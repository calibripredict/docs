Calibri's positions endpoints give you a complete picture of your exposure across every prediction market. You can query open positions, review closed trades with realized P&L, check your total portfolio value, inspect all participants in a given market, or surface the top holders for any outcome token — all using a wallet address with no authentication required.

<Note>
  All positions endpoints are public and read from the Data API at `https://data-api.calibri.com`. They accept any EVM wallet address as a path parameter — no L2 authentication headers are required.
</Note>

---

## Open Positions

Fetch all currently open positions for an address.

```
GET https://data-api.calibri.com/positions/{address}
```

### Path Parameters

<ParamField path="address" type="string" required>
  The EVM wallet address to query (e.g., `0xAbC123...`).
</ParamField>

### Query Parameters

<ParamField query="market" type="string">
  Filter results to a single market by its `condition_id`.
</ParamField>

<ParamField query="size_threshold" type="number">
  Minimum position size to include in the response. Use this to exclude dust positions.
</ParamField>

### Response Fields

<ResponseField name="conditionId" type="string">
  The condition ID of the market this position belongs to.
</ResponseField>

<ResponseField name="tokenId" type="string">
  The ERC-1155 token ID representing the outcome share.
</ResponseField>

<ResponseField name="outcome" type="string">
  Human-readable outcome label (e.g., `"Yes"` or `"No"`).
</ResponseField>

<ResponseField name="outcomeIndex" type="number">
  Numeric index of the outcome (0-based).
</ResponseField>

<ResponseField name="size" type="string">
  Number of outcome shares you hold.
</ResponseField>

<ResponseField name="avgPrice" type="string">
  Your average purchase price per share.
</ResponseField>

<ResponseField name="currentValue" type="string">
  Current market value of your position in pUSD.
</ResponseField>

<ResponseField name="unrealizedPnl" type="string">
  Unrealized profit or loss based on the current market price.
</ResponseField>

<ResponseField name="realizedPnl" type="string">
  Realized profit or loss from any partial sales or redemptions.
</ResponseField>

<ResponseField name="initialValue" type="string">
  The total cost basis of this position — `size × avgPrice` — at the time of entry.
</ResponseField>

<ResponseField name="percentChange" type="string">
  Percentage change between your initial cost basis and the current value, expressed as a decimal (e.g., `"0.083"` = 8.3%).
</ResponseField>

### Example Response

```json
[
  {
    "conditionId": "0xabc...",
    "tokenId": "71321045...",
    "outcome": "Yes",
    "outcomeIndex": 0,
    "size": "150.00",
    "avgPrice": "0.60",
    "initialValue": "90.00",
    "currentValue": "97.50",
    "unrealizedPnl": "7.50",
    "realizedPnl": "0.00",
    "percentChange": "0.083"
  }
]
```

### Example Request

```bash cURL
curl "https://data-api.calibri.com/positions/0xYourWalletAddress?size_threshold=1"
```

<Tip>
  Use `size_threshold=1` (or a value appropriate for your portfolio) to filter out dust positions — fractional shares left over from partial fills that clutter your position list without meaningful value.
</Tip>

## Closed Positions

Fetch positions that have been fully sold or redeemed.

```
GET https://data-api.calibri.com/positions/closed/{address}
```

### Path Parameters

<ParamField path="address" type="string" required>
  The EVM wallet address to query.
</ParamField>

### Example Response

Closed positions include the same fields as open positions, plus:

```json
[
  {
    "conditionId": "0xabc...",
    "tokenId": "71321045...",
    "outcome": "Yes",
    "outcomeIndex": 0,
    "size": "100.00",
    "avgPrice": "0.55",
    "initialValue": "55.00",
    "currentValue": "0.00",
    "unrealizedPnl": "0.00",
    "realizedPnl": "15.00",
    "percentChange": "0.273",
    "closedValue": "70.00",
    "closedTime": "2024-11-15T14:32:00Z"
  }
]
```

| Additional Field | Type | Description |
|---|---|---|
| `closedValue` | string | The total proceeds received when this position was closed. |
| `closedTime` | string | ISO 8601 timestamp of when the position was closed or redeemed. |

### Example Request

```bash cURL
curl "https://data-api.calibri.com/positions/closed/0xYourWalletAddress"
```

## Portfolio Value

Fetch the total current value of all open positions for an address.

```
GET https://data-api.calibri.com/positions/value/{address}
```

### Path Parameters

<ParamField path="address" type="string" required>
  The EVM wallet address to query.
</ParamField>

### Example Response

```json
{
  "value": "412.75",
  "pnl": "62.75",
  "positions_count": 5
}
```

| Field | Type | Description |
|---|---|---|
| `value` | string | Total current market value of all open positions in pUSD. |
| `pnl` | string | Net unrealized profit or loss across all open positions. |
| `positions_count` | number | Total number of open positions. |

### Example Request

```bash cURL
curl "https://data-api.calibri.com/positions/value/0xYourWalletAddress"
```

## Positions in a Market

Fetch all open positions held by any trader within a specific market.

```
GET https://data-api.calibri.com/positions/market/{condition_id}
```

### Path Parameters

<ParamField path="condition_id" type="string" required>
  The condition ID of the market to query.
</ParamField>

### Query Parameters

<ParamField query="limit" type="number">
  Maximum number of results to return. Defaults to 100.
</ParamField>

<ParamField query="offset" type="number">
  Number of results to skip for pagination.
</ParamField>

### Example Request

```bash cURL
curl "https://data-api.calibri.com/positions/market/0xConditionId?limit=20&offset=0"
```

## Top Holders

Fetch the largest holders for a given outcome token in a market.

```
GET https://data-api.calibri.com/positions/top-holders
```

### Query Parameters

<ParamField query="market" type="string" required>
  The condition ID of the market to inspect.
</ParamField>

<ParamField query="outcome_index" type="number">
  Index of the specific outcome to filter by (e.g., `0` for Yes, `1` for No).
</ParamField>

<ParamField query="limit" type="number">
  Maximum number of top holders to return.
</ParamField>

### Example Response

```json
[
  {
    "address": "0xHolder1...",
    "size": "5000.00",
    "avgPrice": "0.52",
    "currentValue": "3250.00"
  },
  {
    "address": "0xHolder2...",
    "size": "3200.00",
    "avgPrice": "0.61",
    "currentValue": "2080.00"
  }
]
```

### Example Request

```bash cURL
curl "https://data-api.calibri.com/positions/top-holders?market=0xConditionId&outcome_index=0&limit=10"
```
