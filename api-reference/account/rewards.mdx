Calibri distributes pUSD daily to market makers who provide qualifying liquidity. If you post bids and asks within a market's maximum spread threshold at or above the minimum order size, you earn a proportional share of that market's daily reward pool. On top of per-market rewards, the platform also runs a maker rebate program that returns a percentage of your trading fees based on your rolling volume. Use the endpoints below to track your earnings, verify your current reward share in real time, and reconcile rebates at the end of each period.

<Note>
  Reward configurations change as markets launch and expire. Poll `/rewards/config` regularly to stay current on which markets are actively rewarding liquidity and what the qualifying thresholds are.
</Note>

---

## How Rewards Are Calculated

Calibri distributes rewards using an open-interest (OI) weighted model. Each eligible market publishes a `rewardsPerDay` budget. Your share of that budget is proportional to your contribution to the total qualifying OI — that is, the resting limit orders you have within `maxSpread` of the mid-price with a size of at least `minSize`.

At current reward rates, qualifying liquidity earns roughly **6% APR** on notional size. Your exact share at any moment is available from the `/rewards/percentages/{address}` endpoint.

## Active Reward Configurations

Retrieve the list of markets currently offering liquidity rewards.

```
GET https://clob.calibri.com/rewards/config
```

No authentication required.

### Example Response

```json
[
  {
    "conditionId": "0xabc...",
    "question": "Will X happen?",
    "rewardsPerDay": "1000",
    "minSize": "20",
    "maxSpread": "0.10",
    "active": true
  }
]
```

| Field | Type | Description |
|---|---|---|
| `conditionId` | string | The market's condition ID. |
| `question` | string | Human-readable market question. |
| `rewardsPerDay` | string | Total pUSD distributed to all qualifying makers per day. |
| `minSize` | string | Minimum resting order size (in shares) required to qualify. |
| `maxSpread` | string | Maximum bid-ask spread allowed for an order to qualify. |
| `active` | boolean | Whether this configuration is currently active. |

### Example Request

```bash cURL
curl "https://clob.calibri.com/rewards/config"
```

## Daily Earnings Per Market

Fetch your reward earnings broken down by market for a specific date.

```
GET https://clob.calibri.com/rewards/earnings/{address}/{date}
```

### Path Parameters

<ParamField path="address" type="string" required>
  Your EVM wallet address.
</ParamField>

<ParamField path="date" type="string" required>
  The date to query in `YYYY-MM-DD` format (e.g., `2024-11-15`).
</ParamField>

### Example Response

```json
[
  {
    "conditionId": "0xabc...",
    "question": "Will X happen?",
    "earnings": "12.40",
    "assetType": "pUSD"
  },
  {
    "conditionId": "0xdef...",
    "question": "Will Y happen before Z?",
    "earnings": "8.75",
    "assetType": "pUSD"
  }
]
```

### Example Request

```bash cURL
curl "https://clob.calibri.com/rewards/earnings/0xYourWalletAddress/2024-11-15"
```

## Real-Time Reward Share Percentages

Fetch your current percentage share of rewards for each market you are actively qualifying in. This endpoint reflects your share at this exact moment based on your live resting orders.

```
GET https://clob.calibri.com/rewards/percentages/{address}
```

### Path Parameters

<ParamField path="address" type="string" required>
  Your EVM wallet address.
</ParamField>

### Example Response

```json
[
  {
    "conditionId": "0xabc...",
    "percentage": "0.0342"
  },
  {
    "conditionId": "0xdef...",
    "percentage": "0.0118"
  }
]
```

`percentage` is your real-time fractional share of the daily reward pool for that market (e.g., `0.0342` means you are earning 3.42% of `rewardsPerDay`).

### Example Request

```bash cURL
curl "https://clob.calibri.com/rewards/percentages/0xYourWalletAddress"
```

## Current Period Maker Rebates

Fetch your accrued fee rebates for the current rebate period.

```
GET https://clob.calibri.com/rebates/current/{address}
```

### Path Parameters

<ParamField path="address" type="string" required>
  Your EVM maker wallet address.
</ParamField>

### Example Response

```json
{
  "rebateAmount": "12.50",
  "volumeTraded": "8500.00",
  "rebateRate": "0.0015"
}
```

| Field | Type | Description |
|---|---|---|
| `rebateAmount` | string | Total fees rebated to you so far this period in pUSD. |
| `volumeTraded` | string | Your maker volume traded during the current period. |
| `rebateRate` | string | Your effective rebate rate (e.g., `0.0015` = 0.15 bps). |

### Example Request

```bash cURL
curl "https://clob.calibri.com/rebates/current/0xYourWalletAddress"
```

## 7-Day Trading Stats

Fetch a summary of your trading activity over the past 7 days. This endpoint requires L2 authentication.

```
GET https://clob.calibri.com/account-stats
```

<Note>
  Requires L2 authentication. Include `POLY_ADDRESS`, `POLY_API_KEY`, `POLY_PASSPHRASE`, `POLY_SIGNATURE`, and `POLY_TIMESTAMP` headers.
</Note>

### Example Response

```json
{
  "totalVolume": "12500.00",
  "totalFees": "12.50",
  "totalTrades": 87,
  "makerVolume": "7500.00",
  "takerVolume": "5000.00"
}
```

| Field | Type | Description |
|---|---|---|
| `totalVolume` | string | Total notional volume traded over the past 7 days. |
| `totalFees` | string | Total fees paid over the past 7 days. |
| `totalTrades` | number | Total number of trades executed. |
| `makerVolume` | string | Volume traded as a maker (resting orders filled by others). |
| `takerVolume` | string | Volume traded as a taker (orders that crossed the spread). |

### Example Request

```bash cURL
curl -X GET "https://clob.calibri.com/account-stats" \
  -H "POLY_ADDRESS: 0xYourWalletAddress" \
  -H "POLY_API_KEY: your-api-key" \
  -H "POLY_PASSPHRASE: your-passphrase" \
  -H "POLY_SIGNATURE: your-hmac-signature" \
  -H "POLY_TIMESTAMP: 1700000000"
```

## Per-Instrument Daily Reward Shares

Fetch your daily liquidity reward earnings and reward share broken down by instrument. This endpoint requires L2 authentication.

```
GET https://clob.calibri.com/account-rewards
```

<Note>
  Requires L2 authentication. Include `POLY_ADDRESS`, `POLY_API_KEY`, `POLY_PASSPHRASE`, `POLY_SIGNATURE`, and `POLY_TIMESTAMP` headers.
</Note>

### Example Response

```json
[
  {
    "conditionId": "0xabc...",
    "question": "Will X happen?",
    "dailyEarnings": "12.40",
    "rewardShare": "0.0342"
  }
]
```

| Field | Type | Description |
|---|---|---|
| `conditionId` | string | The market's condition ID. |
| `question` | string | Human-readable market question. |
| `dailyEarnings` | string | Your earnings from this market today in pUSD. |
| `rewardShare` | string | Your current fractional share of this market's reward pool. |

### Example Request

```bash cURL
curl -X GET "https://clob.calibri.com/account-rewards" \
  -H "POLY_ADDRESS: 0xYourWalletAddress" \
  -H "POLY_API_KEY: your-api-key" \
  -H "POLY_PASSPHRASE: your-passphrase" \
  -H "POLY_SIGNATURE: your-hmac-signature" \
  -H "POLY_TIMESTAMP: 1700000000"
```
