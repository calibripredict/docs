Your account balance reflects all collateral currently available for trading on Calibri. The `/balances` endpoint returns a breakdown of each asset you hold — including the running totals of what you've deposited and withdrawn — so you always have a precise view of your on-platform funds before placing orders.

## Endpoint

```
GET https://clob.calibri.com/balances
```

<Note>
  This endpoint requires L2 authentication. Include the `POLY_ADDRESS`, `POLY_API_KEY`, `POLY_PASSPHRASE`, `POLY_SIGNATURE`, and `POLY_TIMESTAMP` headers with every request.
</Note>

## Response Fields

<ResponseField name="asset" type="string" required>
  The ticker symbol of the asset (e.g., `"pUSD"`).
</ResponseField>

<ResponseField name="balance" type="string" required>
  Your current available balance for this asset, expressed as a decimal string.
</ResponseField>

<ResponseField name="deposited" type="string" required>
  The cumulative amount you have deposited for this asset since account creation.
</ResponseField>

<ResponseField name="withdrawn" type="string" required>
  The cumulative amount you have withdrawn for this asset since account creation.
</ResponseField>

## Example Response

```json
[
  {
    "asset": "pUSD",
    "balance": "1000.50",
    "deposited": "1500.00",
    "withdrawn": "499.50"
  }
]
```

## Example Request

<CodeGroup>

```bash cURL
curl -X GET "https://clob.calibri.com/balances" \
  -H "POLY_ADDRESS: 0xYourWalletAddress" \
  -H "POLY_API_KEY: your-api-key" \
  -H "POLY_PASSPHRASE: your-passphrase" \
  -H "POLY_SIGNATURE: your-hmac-signature" \
  -H "POLY_TIMESTAMP: 1700000000"
```

```typescript TypeScript
const response = await fetch('https://clob.calibri.com/balances', {
  method: 'GET',
  headers: {
    'POLY_ADDRESS': process.env.POLY_ADDRESS!,
    'POLY_API_KEY': process.env.POLY_API_KEY!,
    'POLY_PASSPHRASE': process.env.POLY_PASSPHRASE!,
    'POLY_SIGNATURE': buildL2Signature(), // your HMAC-SHA256 signing utility
    'POLY_TIMESTAMP': String(Math.floor(Date.now() / 1000)),
  },
});

const balances = await response.json();
console.log(balances);
// [{ asset: 'pUSD', balance: '1000.50', deposited: '1500.00', withdrawn: '499.50' }]
```

</CodeGroup>

<Tip>
  Always check your balance before submitting an order. If your available balance is lower than the order's notional value, the exchange will reject the order with an insufficient funds error, which costs an unnecessary round trip.
</Tip>

## Related Endpoints

The following endpoints give you broader context about the exchange and the assets it supports.

### GET /exchange-info

Returns general exchange metadata, including the current fee structure, supported assets, and platform configuration.

```
GET https://clob.calibri.com/exchange-info
```

### GET /collateral-assets

Returns the full list of tokens accepted as collateral on Calibri. Use this to verify that an asset you intend to deposit is supported before initiating a transfer.

```
GET https://clob.calibri.com/collateral-assets
```
