This guide walks you through everything you need to go from a fresh setup to placing your first live order on Calibri. You'll install the SDK, connect your Polygon wallet to get API credentials, browse active prediction markets, and submit a signed limit order — all in a few minutes. By the end you'll have a working client you can build on.

<Steps>
  <Step title="Install the SDK">
    Install the official Calibri client library for your language of choice. The SDK handles request signing, WebSocket connection management, and typed responses for all API surfaces.

    <CodeGroup>
      ```bash TypeScript
      npm install @calibri/client
      ```

      ```bash Python
      pip install calibri-client
      ```
    </CodeGroup>
  </Step>

  <Step title="Connect your wallet">
    Calibri uses a two-layer authentication system. To get started, you sign an EIP-712 typed-data message with your Polygon wallet private key (L1), then send it to `POST /auth/api-key` to receive your API credentials.

    You need:
    - A funded Polygon wallet (MATIC for gas, USDC for collateral)
    - Your wallet's private key available in your environment

    <CodeGroup>
      ```bash cURL
      curl -X POST https://clob.calibri.com/auth/api-key \
        -H "POLY_ADDRESS: 0xYourWalletAddress" \
        -H "POLY_SIGNATURE: 0xYourEIP712Signature" \
        -H "POLY_TIMESTAMP: 1714000000" \
        -H "POLY_NONCE: 0"
      ```

      ```typescript TypeScript
      import { createPublicClient } from '@calibri/client';

      const client = createPublicClient();

      // The SDK handles EIP-712 signing when you provide your private key
      const credentials = await client.createApiCredentials({
        privateKey: process.env.WALLET_PRIVATE_KEY!,
        address: process.env.WALLET_ADDRESS!,
      });

      console.log(credentials);
      // { apiKey: "...", secret: "...", passphrase: "..." }
      ```

      ```python Python
      from calibri import AsyncPublicClient

      client = AsyncPublicClient()

      credentials = await client.create_api_credentials(
          private_key=os.environ["WALLET_PRIVATE_KEY"],
          address=os.environ["WALLET_ADDRESS"],
      )

      print(credentials)
      # { "apiKey": "...", "secret": "...", "passphrase": "..." }
      ```
    </CodeGroup>

    A successful response returns your credentials:

    ```json
    {
      "apiKey": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "secret": "c2VjcmV0QmFzZTY0RW5jb2RlZFN0cmluZw==",
      "passphrase": "my-secure-passphrase"
    }
    ```

    <Warning>
      Store your `secret` and `passphrase` in a secure secrets manager immediately. Calibri does not store these values and cannot retrieve them for you — if you lose them, you must generate new credentials.
    </Warning>
  </Step>

  <Step title="Browse markets">
    With your client initialized, call `GET /markets` on the Market API to list active prediction markets. Use the `active` and `limit` filters to narrow the results.

    <CodeGroup>
      ```typescript TypeScript
      import { createPublicClient } from '@calibri/client';

      const client = createPublicClient();

      const markets = await client.listMarkets({ active: true, limit: 10 });
      console.log(markets);
      ```

      ```python Python
      from calibri import AsyncPublicClient

      client = AsyncPublicClient()

      markets = await client.list_markets(active=True, limit=10)
      print(markets)
      ```

      ```bash cURL
      curl "https://gamma-api.calibri.com/markets?active=true&limit=10"
      ```
    </CodeGroup>

    The response returns an array of market objects. Here's a simplified example:

    ```json
    [
      {
        "id": "0xabc123",
        "question": "Will Candidate A win the 2024 election?",
        "outcomes": ["Yes", "No"],
        "bestBid": 0.62,
        "bestAsk": 0.64,
        "endDate": "2024-11-05T23:59:00Z"
      }
    ]
    ```
  </Step>

  <Step title="Place your first order">
    Once you've picked a market, initialize an authenticated client with your credentials and submit a limit order to `POST /order` on the CLOB API. The example below buys 100 YES shares at a limit price of $0.63.

    <CodeGroup>
      ```typescript TypeScript
      import { createClient } from '@calibri/client';

      const client = createClient({
        apiKey: process.env.CALIBRI_API_KEY!,
        secret: process.env.CALIBRI_SECRET!,
        passphrase: process.env.CALIBRI_PASSPHRASE!,
        address: process.env.WALLET_ADDRESS!,
        privateKey: process.env.WALLET_PRIVATE_KEY!,
      });

      const order = await client.placeOrder({
        marketId: '0xabc123',
        outcome: 'YES',
        side: 'BUY',
        type: 'GTC',
        price: 0.63,
        size: 100,
      });

      console.log(order);
      ```

      ```python Python
      from calibri import AsyncClient

      client = AsyncClient(
          api_key=os.environ["CALIBRI_API_KEY"],
          secret=os.environ["CALIBRI_SECRET"],
          passphrase=os.environ["CALIBRI_PASSPHRASE"],
          address=os.environ["WALLET_ADDRESS"],
          private_key=os.environ["WALLET_PRIVATE_KEY"],
      )

      order = await client.place_order(
          market_id="0xabc123",
          outcome="YES",
          side="BUY",
          order_type="GTC",
          price=0.63,
          size=100,
      )

      print(order)
      ```

      ```bash cURL
      curl -X POST https://clob.calibri.com/order \
        -H "Content-Type: application/json" \
        -H "POLY_ADDRESS: 0xYourWalletAddress" \
        -H "POLY_API_KEY: your-api-key" \
        -H "POLY_PASSPHRASE: your-passphrase" \
        -H "POLY_SIGNATURE: your-l2-hmac-signature" \
        -H "POLY_TIMESTAMP: 1714000000" \
        -d '{
          "marketId": "0xabc123",
          "outcome": "YES",
          "side": "BUY",
          "type": "GTC",
          "price": 0.63,
          "size": 100
        }'
      ```
    </CodeGroup>

    A successful order returns a confirmation with your order ID and status:

    ```json
    {
      "orderId": "ord_7f8e9d0c1b2a",
      "status": "OPEN",
      "marketId": "0xabc123",
      "outcome": "YES",
      "side": "BUY",
      "price": 0.63,
      "size": 100,
      "filledSize": 0,
      "createdAt": "2024-05-01T12:00:00Z"
    }
    ```

    <Tip>
      Use the `GTC` (Good Till Canceled) order type to keep your order resting in the book until it fills or you cancel it. For immediate execution only, use `FOK` (Fill or Kill) — which cancels entirely if it can't fill in full — or `FAK` (Fill and Kill) to partially fill and cancel the remainder.
    </Tip>
  </Step>
</Steps>

<Note>
  Calibri provides a testnet environment for development and integration testing. Point your SDK base URLs at the testnet endpoints to trade with test funds before going live. Contact the Calibri team or check the developer portal for the current testnet base URLs.
</Note>
