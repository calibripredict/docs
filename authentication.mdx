Calibri protects its trading endpoints with a two-layer authentication system. In Layer 1 (L1), you prove ownership of your Polygon wallet by signing an EIP-712 typed-data message, then exchange that signature for a set of API credentials. In Layer 2 (L2), you use those credentials to sign every authenticated request with HMAC-SHA256. This design keeps your wallet private key out of your request headers while still tying every API action to a verified on-chain identity.

## Overview

| Layer | What it does | When you use it |
|---|---|---|
| **L1 — Wallet signature** | Proves wallet ownership via EIP-712 signed message | Once, to create or derive API credentials |
| **L2 — HMAC-SHA256** | Signs each request using your `apiKey`, `secret`, and `passphrase` | On every authenticated API call |

Public endpoints (market discovery, live pricing) require no authentication. All order management and account endpoints require a valid L2 signature.

## Step 1: Create API credentials (L1)

To create credentials, sign an EIP-712 typed-data message with your wallet private key and send it to `POST /auth/api-key`. The server verifies your signature against your wallet address and returns a fresh set of credentials.

Send these headers with your request:

| Header | Description |
|---|---|
| `POLY_ADDRESS` | Your Polygon wallet address |
| `POLY_SIGNATURE` | Your EIP-712 L1 signature |
| `POLY_TIMESTAMP` | Current Unix timestamp in seconds |
| `POLY_NONCE` | Credential nonce — use `0` for your first credential set |

<CodeGroup>
  ```bash cURL
  curl -X POST https://clob.calibri.com/auth/api-key \
    -H "POLY_ADDRESS: 0xYourWalletAddress" \
    -H "POLY_SIGNATURE: 0xYourEIP712Signature" \
    -H "POLY_TIMESTAMP: 1714000000" \
    -H "POLY_NONCE: 0"
  ```

  ```typescript TypeScript
  import { Wallet } from 'ethers';
  import { signL1Message } from '@calibri/client';

  const wallet = new Wallet(process.env.WALLET_PRIVATE_KEY!);
  const timestamp = Math.floor(Date.now() / 1000);
  const nonce = 0;

  const signature = await signL1Message(wallet, timestamp, nonce);

  const response = await fetch('https://clob.calibri.com/auth/api-key', {
    method: 'POST',
    headers: {
      'POLY_ADDRESS': wallet.address,
      'POLY_SIGNATURE': signature,
      'POLY_TIMESTAMP': String(timestamp),
      'POLY_NONCE': String(nonce),
    },
  });

  const credentials = await response.json();
  console.log(credentials);
  ```

  ```python Python
  import time
  import httpx
  from calibri.auth import sign_l1_message

  timestamp = int(time.time())
  nonce = 0

  signature = sign_l1_message(
      private_key=os.environ["WALLET_PRIVATE_KEY"],
      timestamp=timestamp,
      nonce=nonce,
  )

  async with httpx.AsyncClient() as http:
      response = await http.post(
          "https://clob.calibri.com/auth/api-key",
          headers={
              "POLY_ADDRESS": os.environ["WALLET_ADDRESS"],
              "POLY_SIGNATURE": signature,
              "POLY_TIMESTAMP": str(timestamp),
              "POLY_NONCE": str(nonce),
          },
      )

  credentials = response.json()
  print(credentials)
  ```
</CodeGroup>

A successful response returns your credentials:

```json
{
  "apiKey": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "secret": "c2VjcmV0QmFzZTY0RW5jb2RlZFN0cmluZw==",
  "passphrase": "my-secure-passphrase"
}
```

<Warning>
  Store your `secret` and `passphrase` in a secure secrets manager (such as AWS Secrets Manager, HashiCorp Vault, or an encrypted `.env` file) immediately after receiving them. Calibri does not retain these values — if you lose them, you must generate a new credential set.
</Warning>

## Step 2: Sign authenticated requests (L2)

Every request to an authenticated endpoint must include an HMAC-SHA256 signature computed from your `secret`. Build the signature as follows:

```text
message   = timestamp + HTTP_METHOD + request_path [+ body]
signature = urlsafeBase64WithPadding(HMAC-SHA256(base64Decode(secret), message))
```

- `timestamp` — current Unix seconds as a string
- `HTTP_METHOD` — uppercase verb, e.g. `GET`, `POST`
- `request_path` — path and query string, e.g. `/orders?status=OPEN`
- `body` — the raw JSON request body string (omit for requests with no body)

Include these headers on every authenticated request:

| Header | Value |
|---|---|
| `POLY_ADDRESS` | Your wallet address |
| `POLY_API_KEY` | Your `apiKey` |
| `POLY_PASSPHRASE` | Your `passphrase` |
| `POLY_SIGNATURE` | The HMAC-SHA256 signature you computed |
| `POLY_TIMESTAMP` | Unix timestamp in seconds (must match the one used to build the signature) |

<CodeGroup>
  ```typescript TypeScript
  import crypto from 'crypto';

  function buildL2Signature(
    secret: string,
    timestamp: number,
    method: string,
    path: string,
    body?: string
  ): string {
    const message = `${timestamp}${method}${path}${body ?? ''}`;
    const key = Buffer.from(secret, 'base64');
    const sig = crypto.createHmac('sha256', key).update(message).digest();
    return sig.toString('base64url').replace(/=+$/, '');
  }

  // Example: signing a POST /order request
  const timestamp = Math.floor(Date.now() / 1000);
  const body = JSON.stringify({ marketId: '0xabc123', side: 'BUY', price: 0.63, size: 100 });
  const signature = buildL2Signature(
    process.env.CALIBRI_SECRET!,
    timestamp,
    'POST',
    '/order',
    body
  );

  const response = await fetch('https://clob.calibri.com/order', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'POLY_ADDRESS': process.env.WALLET_ADDRESS!,
      'POLY_API_KEY': process.env.CALIBRI_API_KEY!,
      'POLY_PASSPHRASE': process.env.CALIBRI_PASSPHRASE!,
      'POLY_SIGNATURE': signature,
      'POLY_TIMESTAMP': String(timestamp),
    },
    body,
  });
  ```

  ```python Python
  import hmac
  import hashlib
  import base64
  import time

  def build_l2_signature(
      secret: str,
      timestamp: int,
      method: str,
      path: str,
      body: str = '',
  ) -> str:
      message = f"{timestamp}{method}{path}{body}"
      key = base64.b64decode(secret)
      sig = hmac.new(key, message.encode(), hashlib.sha256).digest()
      return base64.urlsafe_b64encode(sig).rstrip(b'=').decode()

  # Example: signing a POST /order request
  import json, httpx

  timestamp = int(time.time())
  body = json.dumps({"marketId": "0xabc123", "side": "BUY", "price": 0.63, "size": 100})
  signature = build_l2_signature(
      secret=os.environ["CALIBRI_SECRET"],
      timestamp=timestamp,
      method="POST",
      path="/order",
      body=body,
  )

  async with httpx.AsyncClient() as http:
      response = await http.post(
          "https://clob.calibri.com/order",
          content=body,
          headers={
              "Content-Type": "application/json",
              "POLY_ADDRESS": os.environ["WALLET_ADDRESS"],
              "POLY_API_KEY": os.environ["CALIBRI_API_KEY"],
              "POLY_PASSPHRASE": os.environ["CALIBRI_PASSPHRASE"],
              "POLY_SIGNATURE": signature,
              "POLY_TIMESTAMP": str(timestamp),
          },
      )
  ```
</CodeGroup>

<Tip>
  The SDK handles L2 signature construction automatically when you initialize an authenticated client. You only need to build signatures manually if you're making raw HTTP requests.
</Tip>

## Deriving existing credentials

If you've already created credentials and need to retrieve your `apiKey` (but not the secret or passphrase), send a `GET /auth/derive-api-key` request with the same L1 headers used during creation. This is useful if you need to look up which key is associated with a given wallet and nonce.

<CodeGroup>
  ```bash cURL
  curl https://clob.calibri.com/auth/derive-api-key \
    -H "POLY_ADDRESS: 0xYourWalletAddress" \
    -H "POLY_SIGNATURE: 0xYourEIP712Signature" \
    -H "POLY_TIMESTAMP: 1714000000" \
    -H "POLY_NONCE: 0"
  ```

  ```typescript TypeScript
  const response = await fetch('https://clob.calibri.com/auth/derive-api-key', {
    method: 'GET',
    headers: {
      'POLY_ADDRESS': wallet.address,
      'POLY_SIGNATURE': signature,
      'POLY_TIMESTAMP': String(timestamp),
      'POLY_NONCE': '0',
    },
  });

  const { apiKey } = await response.json();
  ```
</CodeGroup>

<Note>
  `GET /auth/derive-api-key` returns only your `apiKey` — it does not return the `secret` or `passphrase`. If you've lost either of those, generate a fresh credential set with `POST /auth/api-key` using a new nonce.
</Note>

## Public vs authenticated endpoints

| Endpoint group | Auth required | Notes |
|---|---|---|
| `GET /markets` | None | Browse and search all markets |
| `GET /markets/{id}` | None | Fetch a single market by ID |
| `GET /price?token_id={id}&side={side}` | None | Best bid or ask price for a token |
| `GET /midpoint?token_id={id}` | None | Midpoint price for a token |
| `GET /spread?token_id={id}` | None | Bid-ask spread for a token |
| `GET /book?token_id={id}` | None | Full order book snapshot for a token |
| `POST /order` | L2 | Place a new order |
| `DELETE /order/{id}` | L2 | Cancel an open order |
| `GET /data/orders` | L2 | List your open orders |
| `GET /positions/{address}` | L2 | View your outcome token holdings |
| `POST /auth/api-key` | L1 | Create API credentials |
| `GET /auth/derive-api-key` | L1 | Look up your API key |

## Error codes

<AccordionGroup>
  <Accordion title="401 Unauthorized">
    Your request is missing a required authentication header, the signature is invalid, or the timestamp is outside the acceptable skew window (±30 seconds). Double-check that:

    - Your `POLY_TIMESTAMP` reflects the current Unix time in seconds.
    - You're signing the correct message string: `timestamp + METHOD + path + body`.
    - Your `secret` is base64-decoded before being used as the HMAC key.
  </Accordion>

  <Accordion title="403 Forbidden">
    Your credentials are valid but you don't have permission to perform the requested action. Common causes include:

    - Attempting to cancel an order that belongs to a different wallet address.
    - Accessing an endpoint that requires a higher permission tier than your current credentials allow.
    - Your API key has been revoked — generate a new credential set to regain access.
  </Accordion>

  <Accordion title="429 Rate Limited">
    You've exceeded the allowed request rate for your credential tier. Calibri enforces per-second and per-minute rate limits on all authenticated endpoints. To handle this gracefully:

    - Implement exponential backoff on `429` responses.
    - Batch market data fetches where possible.
    - Use the WebSocket feed for continuous price updates instead of polling the REST API.
  </Accordion>
</AccordionGroup>
