The `calibri-client` package is an async-first Python SDK for the Calibri prediction market engine. It exposes `AsyncPublicClient` and `AsyncSecureClient` as the primary interfaces, with synchronous `PublicClient` and `SecureClient` wrappers available for scripts and environments where running an event loop is not practical. The SDK uses Python's `Decimal` type throughout for all price and size fields, so you never lose precision to floating-point arithmetic when constructing or reading orders.

<Note>
  `calibri-client` requires **Python 3.9 or later**. For best results, use Python 3.11+ where `asyncio` performance and error messages are significantly improved.
</Note>

## Quick start

The example below fetches active markets and prints the implied probabilities for each outcome.

```python
import asyncio
from calibri import AsyncPublicClient

async def main():
    client = AsyncPublicClient()
    markets = await client.list_markets(active=True, limit=5)
    for m in markets:
        print(f"{m.question}: Yes={m.outcome_prices[0]}, No={m.outcome_prices[1]}")

asyncio.run(main())
```

To place orders, create an `AsyncSecureClient` with your credentials and call `place_limit_order` or `place_market_order`:

```python
import asyncio
from decimal import Decimal
from calibri import AsyncSecureClient, OrderSide

async def main():
    client = AsyncSecureClient(
        api_key='your_api_key',
        secret='your_secret',
        passphrase='your_passphrase',
        address='0xYourWalletAddress',
    )

    order = await client.place_limit_order(
        token_id='71321045679252212594626385532706912750332728571942532289631379312455583992563',
        side=OrderSide.BUY,
        price=Decimal('0.62'),
        size=Decimal('50'),
    )
    print(f"Placed order {order.order_id} — status: {order.status}")

asyncio.run(main())
```

<Tip>
  Use the `async with` context manager to ensure the underlying HTTP session is closed cleanly when your code finishes:

  ```python
  async with AsyncSecureClient(...) as client:
      markets = await client.list_markets(active=True)
  # Session is closed automatically here
  ```
</Tip>

## Public client

`AsyncPublicClient` (and its synchronous counterpart `PublicClient`) provide unauthenticated access to market data and the order book. No API credentials are required.

### `list_markets(**params)`

Fetch a list of markets with optional keyword filters.

| Parameter | Type | Description |
|-----------|------|-------------|
| `active` | `bool` | Return only active markets |
| `closed` | `bool` | Return only closed markets |
| `limit` | `int` | Maximum results per page (default `100`) |
| `offset` | `int` | Pagination offset |
| `tag` | `str` | Filter by market tag |

```python
from calibri import AsyncPublicClient

async def list_active_markets():
    client = AsyncPublicClient()
    markets = await client.list_markets(active=True, tag='crypto', limit=20)

    for m in markets:
        print(f"[{m.slug}] {m.question}")
        print(f"  Volume: ${m.volume:,}  Active: {m.active}")
```

### Pagination with `AsyncPaginator`

For large result sets, use `AsyncPaginator` to iterate through every page automatically. It calls `list_markets` repeatedly, advancing the offset, and yields one market object at a time.

```python
from calibri import AsyncPublicClient, AsyncPaginator

async def fetch_all_markets():
    client = AsyncPublicClient()
    async for market in AsyncPaginator(client.list_markets, active=True):
        print(market.slug)
```

### `fetch_market(id)`

Fetch a single market by its ID or slug.

```python
async def show_market():
    client = AsyncPublicClient()

    # By slug
    market = await client.fetch_market('will-eth-flip-btc-2025')
    print(market.question)
    print(market.clob_token_ids)   # List of token IDs, one per outcome
```

### `fetch_order_book(token_id)`

Fetch the full depth-of-book for a token. The response contains sorted price levels for both the bid and ask sides.

```python
async def show_book():
    client = AsyncPublicClient()
    book = await client.fetch_order_book(
        '71321045679252212594626385532706912750332728571942532289631379312455583992563'
    )

    print(f"Bids: {len(book.bids)} levels")
    print(f"Asks: {len(book.asks)} levels")

    if book.bids and book.asks:
        spread = book.asks[0].price - book.bids[0].price
        print(f"Spread: {spread}")
```

### `fetch_price(token_id, side)`, `fetch_midpoint(token_id)`, and `fetch_spread(token_id)`

Fetch price summary data for a token.

```python
from calibri import AsyncPublicClient, OrderSide

async def show_prices():
    client = AsyncPublicClient()
    token_id = '71321045679252212594626385532706912750332728571942532289631379312455583992563'

    bid      = await client.fetch_price(token_id, OrderSide.BUY)
    ask      = await client.fetch_price(token_id, OrderSide.SELL)
    midpoint = await client.fetch_midpoint(token_id)
    spread   = await client.fetch_spread(token_id)

    print(f"Bid: {bid}  Ask: {ask}  Mid: {midpoint}  Spread: {spread}")
```

### `fetch_last_trade_price(token_id)`

Fetch the price at which the most recent trade executed.

```python
last_price = await client.fetch_last_trade_price(token_id)
print(f"Last trade: {last_price}")
```

## Secure client

`AsyncSecureClient` extends the public client with authenticated endpoints for order placement, cancellation, position tracking, and session management. Pass your credentials at construction time.

```python
from calibri import AsyncSecureClient

client = AsyncSecureClient(
    api_key='your_api_key',
    secret='your_secret',
    passphrase='your_passphrase',
    address='0xYourWalletAddress',
)
```

### `place_limit_order(...)`

Place a resting limit order on the Calibri CLOB. The order stays in the book until it fills, is cancelled, or expires.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `token_id` | `TokenId` | ✓ | CLOB token ID for the outcome |
| `side` | `OrderSide` | ✓ | `OrderSide.BUY` or `OrderSide.SELL` |
| `price` | `Decimal` | ✓ | Limit price between `0` and `1` |
| `size` | `Decimal` | ✓ | Order size in USDC |
| `order_type` | `OrderType` | | `GTC` (default) or `GTD` |
| `post_only` | `bool` | | Reject if order would immediately cross |
| `expiration` | `int` | | Unix timestamp for GTD expiry |

```python
from decimal import Decimal
from calibri import AsyncSecureClient, OrderSide, OrderType
import time

async def place_orders():
    client = AsyncSecureClient(...)
    token_id = '71321045679252212594626385532706912750332728571942532289631379312455583992563'

    # Good-till-cancelled buy
    gtc = await client.place_limit_order(
        token_id=token_id,
        side=OrderSide.BUY,
        price=Decimal('0.65'),
        size=Decimal('100'),
        post_only=True,
    )
    print(f"GTC order: {gtc.order_id}")

    # Good-till-date sell expiring in one hour
    gtd = await client.place_limit_order(
        token_id=token_id,
        side=OrderSide.SELL,
        price=Decimal('0.72'),
        size=Decimal('50'),
        order_type=OrderType.GTD,
        expiration=int(time.time()) + 3600,
    )
    print(f"GTD order: {gtd.order_id}")
```

### `place_market_order(token_id, side, size)`

Place a Fill-or-Kill market order. The full order must fill at the current best price or it is cancelled entirely — no partial fills.

```python
from decimal import Decimal
from calibri import AsyncSecureClient, OrderSide

async def market_buy():
    client = AsyncSecureClient(...)

    order = await client.place_market_order(
        token_id='71321045679252212594626385532706912750332728571942532289631379312455583992563',
        side=OrderSide.BUY,
        size=Decimal('200'),
    )

    print(f"Status:      {order.status}")     # "matched" or "unmatched"
    print(f"Filled size: {order.filled_size}")
```

<Warning>
  Market orders are Fill-or-Kill. If there is insufficient liquidity to fill the entire order at the moment of submission, the order is cancelled and no partial fill is recorded.
</Warning>

### `cancel_order(order_id)`, `cancel_orders(order_ids)`, and `cancel_all_orders()`

Cancel a single order by ID, a batch of orders by ID list, or every open order at once.

```python
# Cancel a single order
await client.cancel_order('order_abc123')

# Cancel multiple orders in one call
await client.cancel_orders(['order_abc123', 'order_def456'])

# Cancel every open order — useful for emergency risk management
await client.cancel_all_orders()
```

### `fetch_positions(address)`

Fetch all open positions for a given wallet address. Iterate the results to inspect unrealized P&L or current exposure per market.

```python
from calibri import AsyncSecureClient
from decimal import Decimal

async def show_portfolio():
    client = AsyncSecureClient(...)
    positions = await client.fetch_positions('0xYourWalletAddress')

    total_value = Decimal('0')
    for pos in positions:
        total_value += pos.current_value
        print(f"Token:       {pos.token_id[:12]}...")
        print(f"Size:        {pos.size}")
        print(f"Avg price:   {pos.avg_price}")
        print(f"Current val: {pos.current_value}")
        print(f"Unrealized:  {pos.unrealized_pnl}")
        print(f"Realized:    {pos.realized_pnl}")
        print('---')

    print(f"Total portfolio value: ${total_value}")
```

### `fetch_balances()`

Fetch your current USDC balance and the amount locked as margin for open orders.

```python
async def check_balance():
    client = AsyncSecureClient(...)
    balances = await client.fetch_balances()

    print(f"Available USDC: {balances.usdc}")
    print(f"Locked USDC:    {balances.locked_usdc}")

    if balances.usdc < Decimal('10'):
        print("Warning: low balance — consider topping up before placing orders.")
```

### `list_open_orders(**params)` and `fetch_order(order_id)`

Retrieve your open orders or look up a specific order by ID.

```python
# All open orders
open_orders = await client.list_open_orders()

# Open orders filtered by market
market_orders = await client.list_open_orders(market_id='0x1234abcd...')

for order in market_orders:
    print(f"{order.side} {order.size} @ {order.price} — {order.status}")

# Fetch one order
order = await client.fetch_order('order_abc123')
print(f"Filled: {order.filled_size} / {order.size}")
```

### `list_trades(**params)`

Fetch your trade history with optional filters such as `market_id`, `token_id`, and `limit`.

```python
async def show_trades():
    client = AsyncSecureClient(...)
    trades = await client.list_trades(limit=50)

    for trade in trades:
        print(f"{trade.side} {trade.size} @ {trade.price}  —  {trade.created_at}")
```

### `send_heartbeat()` and `set_auto_cancel(cancel_after)`

Maintain your session with a periodic heartbeat, or configure a dead man's switch that cancels open orders if the switch is not refreshed in time.

```python
import asyncio
from calibri import AsyncSecureClient

async def run_with_heartbeat():
    client = AsyncSecureClient(...)

    # Cancel all open orders if no heartbeat within 30 seconds
    await client.set_auto_cancel(cancel_after=30)

    while True:
        await client.send_heartbeat()
        await asyncio.sleep(20)          # Refresh before the 30-second window expires
```

<Tip>
  Set `cancel_after=0` to disable the auto-cancel switch without cancelling any open orders.
</Tip>

## Synchronous client

`PublicClient` and `SecureClient` are synchronous wrappers around the async clients. They expose the same methods with identical signatures — just call them without `await`.

```python
from calibri import PublicClient, SecureClient, OrderSide
from decimal import Decimal

# Synchronous public client
pub = PublicClient()
markets = pub.list_markets(active=True, limit=10)
for m in markets:
    print(m.question)

# Synchronous secure client
sec = SecureClient(
    api_key='your_api_key',
    secret='your_secret',
    passphrase='your_passphrase',
    address='0xYourWalletAddress',
)
order = sec.place_limit_order(
    token_id='71321045...',
    side=OrderSide.BUY,
    price=Decimal('0.60'),
    size=Decimal('25'),
)
print(order.order_id)
```

Use the synchronous clients in situations where you cannot run an event loop — for example, in Jupyter notebooks that don't support top-level `await`, CLI scripts, or Django views. For long-running services, automation systems, or any code that handles multiple markets concurrently, prefer the async clients: they let you issue multiple requests in parallel with `asyncio.gather`, which dramatically reduces latency.

## Working with Decimal

Calibri's Python SDK uses `Decimal` for every price and size field. This prevents the rounding errors that occur when floating-point numbers represent values like `0.65` or `0.10`. Always construct prices and sizes as `Decimal` strings rather than Python `float` literals.

```python
from decimal import Decimal
from calibri import AsyncSecureClient, OrderSide

client = AsyncSecureClient(...)

# ✅ Correct — pass Decimal constructed from a string
order = await client.place_limit_order(
    token_id='71321045679252212594626385532706912750332728571942532289631379312455583992563',
    side=OrderSide.BUY,
    price=Decimal('0.65'),
    size=Decimal('100'),
)
print(f"Order status: {order.status}, filled: {order.filled_size}")

# ❌ Avoid — float literals introduce imprecision
# price=Decimal(0.65)   ->  Decimal('0.6499999999999999555910790149937383830547332763671875')
```

The SDK also uses Python's `datetime` type for all timestamp fields (such as `created_at` on an order), and typed string aliases — `MarketId`, `ConditionId`, `TokenId`, and `EvmAddress` — in function signatures. These aliases are plain `str` at runtime but surface intent in IDE tooltips and type checkers.

## Error handling

The SDK raises two exception types. Catch them individually to handle API-level errors separately from HTTP transport errors.

| Exception | When raised | Key attributes |
|-----------|-------------|----------------|
| `CalibrError` | API returned a structured error payload | `code: str`, `message: str` |
| `CalibrHTTPError` | Unexpected HTTP status (e.g. 500, 429) | `status_code: int`, `message: str` |

```python
from calibri import AsyncSecureClient, OrderSide, CalibrError, CalibrHTTPError
from decimal import Decimal

async def safe_order():
    client = AsyncSecureClient(...)

    try:
        order = await client.place_limit_order(
            token_id='71321045...',
            side=OrderSide.BUY,
            price=Decimal('0.65'),
            size=Decimal('100'),
        )
        print(f"Order placed: {order.order_id}")

    except CalibrError as e:
        # Structured API error — inspect e.code for programmatic handling
        print(f"API error [{e.code}]: {e.message}")
        if e.code == 'INSUFFICIENT_FUNDS':
            print("Top up your USDC balance and retry.")

    except CalibrHTTPError as e:
        # Unexpected HTTP error — may be transient
        print(f"HTTP {e.status_code}: {e.message}")
        if e.status_code == 429:
            print("Rate limited — back off and retry.")
```
